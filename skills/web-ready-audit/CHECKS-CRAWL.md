# Crawlability and SEO checks

Judge each rule from the probe facts ([PROBE.md](PROBE.md)) and the source. Tiers: **B** Blocker, **S** Should fix, **N** Nice to have. A page "meant to rank" is the homepage or any content template; auth, cart, account and search-result pages may be noindex by design.

For a finding whose cause is in the source, cite the line that emits it. When an environment check gates the value (`VERCEL_ENV`, `NODE_ENV`, `CONTEXT`), name the variable and the value production gets.

## Status and redirects

- Homepage final `status` is not 200: B.
- `blocked` is set: report the page as blocked by a bot challenge (crawlers may be blocked too, so say to check the challenge rules); its other checks are not verifiable.
- Homepage reaches 200 through more than one redirect hop: S.
- A page taken from the sitemap redirects or ends non-200: S. A sitemap lists final, indexable URLs only.

## Indexing directives

- `noindex` in `html.metaRobots` (`robots` or `googlebot`) or in `xRobotsTag`, on a page meant to rank: B.
- `nofollow` site-wide in the same places: S.
- **Disallow plus noindex**: a page with `noindex` whose `robotsTxt.verdict` is `disallowed`: S. Google never fetches the page, so it never sees the noindex and can still index the bare URL. To deindex, allow crawling.
- A noindex page with `inSitemap` true: S.

## robots.txt

- `robots.googlebot.verdict` is `disallowed` (`Disallow: /` for `*` or Googlebot): B.
- `status` 5xx, or an `error` (timeout, connection): B. Google treats an unreachable robots.txt as a full disallow.
- 200 with a `text/html` content type (usually an SPA fallback serving `index.html`): S.
- 4xx: N. Google crawls everything; a robots.txt is still the place to list the sitemap.
- A `noindex:` line in `otherLines`: S, Google has not supported it since 2019. Other lines such as `crawl-delay:`: never a finding (Google ignores them, Bing honors them).
- A sitemap exists but `sitemap.declaredInRobots` is false: N.
- `robots.txt` is generated in the source with an environment branch: confirm the production branch allows crawling, citing the line.

## Sitemap

- No sitemap file answers 200: S.
- A sitemap file is `not-xml` or served as `text/html`: S.
- `sitemap.hosts` holds a host other than the audited one (localhost, a preview or staging host, a raw IP): B.
- `sitemap.hosts` holds `http://` while the site is served over https: S.
- One file with more than 50,000 `locs` or over 50 MB: S, search engines reject it.
- `distinctLastmods` is 1 across many URLs (every lastmod is the build time): N. Accurate lastmod or none.
- `priority` and `changefreq` are ignored by Google: never require them.

## Canonical

- No canonical (`html.canonicals` empty and no `canonicalHeader`) on a page meant to rank: S.
- **Wrong canonical**: it points to another host, localhost, `http://` on an https site, a preview host, or the homepage from a non-home page: B. In the source, look for the base URL that builds it (`metadataBase`, a `SITE_URL` env var, a hard-coded origin).
- Several canonicals with different targets (tags plus header included): S. Google may ignore all of them.
- `canonicalTarget.status` 4xx or 5xx: B. A redirect: S, point at the final URL.
- Relative `href`: N, Google resolves it but absolute is safer.
- A paginated page (`?page=2`, `/page/2`) canonical to page 1: S. Each page is self-canonical.

## Title and description

- Title missing or empty: B. A starter-template placeholder (`Vite + React`, `Vite App`, `React App`, `Create Next App`, or similar): B.
- More than one `<title>`: S. The same title on pages of different templates: S.
- Over about 60 characters: N, a warning only. Results truncate by pixel width; there is no length limit.
- Description missing on a page meant to rank: S. A starter-template placeholder (`Generated by create next app`, `Web site created using create-react-app`): B. The same description across templates: S. Over about 160 characters: N, a warning only.
- Meta keywords: never a finding.

## Document basics

- `lang` missing on `<html>`: S (WCAG 3.1.1; screen readers pick the voice from it). A `lang` that does not match the content's language: S.
- `viewport` missing: B, mobile renders at desktop width. `user-scalable=no` or `maximum-scale` below 5: S, it blocks zoom.
- **Client-rendered shell**: `html.emptyMount` set with a low `bodyTextLength`. Head tags set by client code (Helmet, `useHead`, a router `head()` without SSR) are missing from the raw HTML, so the findings above already fire. Give the fix as moving them into the served HTML: prerender, SSR, or static tags in `index.html`.
- `hreflang` present: each page lists itself and an `x-default`; alternates on other hosts or ending non-200: S.

## Preview and staging hosts

- Find the project's other hosts: the platform default host (`*.vercel.app`, `*.netlify.app`, `*.pages.dev`, `*.github.io`) from `platform` and the deploy config, and staging or preview hosts named in the source or CI. Probe each homepage found with `--pages-only`.
- Such a host answers 200, carries no `noindex`, and robots.txt allows it, while it is not the production host: B. Fix: `X-Robots-Tag: noindex` on every non-production host, or a 301 to production. Vercel noindexes its own preview URLs, but not a custom domain assigned to a preview branch.
- No other host found: not verifiable; name it in the header.

## Search engine verification

- No token in any page's `html.verification` and none in `dnsVerification`: S. Word it as "no Search Console or Bing verification found; ignore if verified another way (HTML file, Analytics or Tag Manager, DNS on a parent domain)", and add a "verify yourself" item: the sitemap is submitted in Search Console.

## AI crawlers

- Every bot in `robots.aiCrawlers` has `group` `*` or null: N, "no explicit AI-crawler policy". State what the `*` group means for them.
- Search-type bots (OAI-SearchBot, Claude-SearchBot, PerplexityBot) are disallowed: N. The site drops out of those assistants' answers; confirm it is intended. `Google-Extended` controls AI training only and does not affect Google Search.
- CDN-level bot blocking (for example Cloudflare's AI-bot setting) is invisible to the probe: not verifiable.
